# لوحة مدراء القطاعات

موقع + بوت دسكورد في تطبيق واحد.

- `/` لوحة المدراء (كل مدير يشوف قطاعه)
- `/admin` لوحة الإدارة (للمالك فقط، صفحة منفصلة)

## التشغيل محلياً

1. ادخل https://discord.com/developers/applications وسوّ تطبيق جديد.
2. من تبويب **Bot**: انسخ التوكن، وفعّل **Server Members Intent**.
3. من تبويب **OAuth2**: انسخ Client ID و Client Secret، وأضف في Redirects:
   `http://localhost:3000/callback`
4. ادعُ البوت للسيرفر بصلاحيات `bot` و `applications.commands`.
5. انسخ `.env.example` إلى `.env` واملأه.
6. نفّذ:
   ```
   npm install
   npm run dev
   ```
   وافتح http://localhost:3000 (يحتاج Node 20.6 أو أحدث).
   لا تفتح `index.html` مباشرة من الملفات، لازم عن طريق السيرفر.

## النشر على Render

1. ارفع المشروع على GitHub (ملف `.gitignore` يمنع رفع `.env` والبيانات).
2. في Render: **New** ← **Blueprint** واختر المستودع، وهو يقرأ `render.yaml` تلقائياً.
3. عبّي المتغيرات: `DISCORD_TOKEN` و `CLIENT_ID` و `CLIENT_SECRET` و `GUILD_ID`.
4. بعد النشر ينعطيك رابط مثل `https://sector-dashboard.onrender.com`.
   أضف هذا الرابط مع `/callback` في Discord Developer Portal ← OAuth2 ← Redirects:
   `https://sector-dashboard.onrender.com/callback`
   (الموقع يأخذ رابطه تلقائياً من Render، ما تحتاج تكتب BASE_URL).

ملاحظات مهمة:
- البيانات والصور المرفوعة تنحفظ في المجلد `DATA_DIR`. على Render لازم **قرص دائم (Disk)** عشان ما تنمسح مع كل نشر، وهو مفعّل في `render.yaml` ويحتاج خطة مدفوعة.
- الخطط المجانية على Render تنام بعد فترة خمول، ولما ينام السيرفر ينقطع البوت (الأوامر ما تشتغل لين يصحى). للبوت الأفضل خطة مدفوعة تبقى شغالة.

## لوحة الإدارة (`/admin`)

- **القطاعات**: أضف القطاعات واربط كل قطاع برتبة دسكورد (الأعضاء، والضباط اختياري).
- **المدراء والصلاحيات**: أضف المدراء بايديهم، واختر القطاعات اللي يشوفونها، وفعّل "يقدر يعدّل".
- **الشعار والخلفيات**: ارفع الشعار وخلفية صفحة الدخول وخلفية اللوحات، وغيّر اسم الموقع واللون الرئيسي ودرجة التعتيم.
- **الإشعارات (ويب هوك)**: الصق رابط ويب هوك دسكورد، فيوصل إشعار لقناتك عند بدء وإنهاء المباشرة وعند إضافة أو حذف تحذير.
  لإنشاء الرابط: إعدادات القناة ← التكاملات ← ويب هوك ← ويب هوك جديد ← نسخ الرابط.

## أوامر البوت

- `/duty` بدء المباشرة، `/endduty` إنهاؤها، `/myhours` ساعاتي.
- `/warn` إضافة تحذير (للمصرّح لهم بالتعديل فقط).

## نسخ احتياطية

كل البيانات في `data/db.json` والصور في `data/uploads` (أو داخل `DATA_DIR`). خذ منها نسخة دورياً.
