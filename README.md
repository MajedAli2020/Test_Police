# لوحة مدراء القطاعات

موقع + بوت دسكورد في تطبيق واحد.

## التشغيل

1. ادخل https://discord.com/developers/applications وسوّ تطبيق جديد.
2. من تبويب **Bot**: انسخ التوكن، وفعّل **Server Members Intent**.
3. من تبويب **OAuth2**: انسخ Client ID و Client Secret، وأضف في Redirects الرابط:
   `BASE_URL/callback` (مثال: `http://localhost:3000/callback`).
4. ادعُ البوت للسيرفر بصلاحيات `bot` و `applications.commands`.
5. انسخ `.env.example` إلى `.env` واملأه.
6. نفّذ:
   ```
   npm install
   npm start
   ```
   (يحتاج Node 20.6 أو أحدث)

## الاستخدام

- ادخل الموقع بحسابك (الايدي حقك هو المالك) ← تبويب **الإدارة**:
  - أضف القطاعات واربط كل قطاع برتبة دسكورد (الأعضاء + الضباط اختياري).
  - أضف المدراء بايديهم، واختر القطاعات اللي يشوفونها، وفعّل "يقدر يعدّل" لمن تبي.
- أوامر البوت داخل السيرفر:
  - `/duty` بدء المباشرة، `/endduty` إنهاؤها، `/myhours` ساعاتي.
  - `/warn` إضافة تحذير (للمصرّح لهم بالتعديل فقط).
- تحذيرات القطاع تقدر تضيفها وتحذفها من الموقع كذلك.

## ملاحظات

- لازم يشتغل على استضافة دائمة (VPS أو Railway أو Render...)، ويكون `BASE_URL` هو رابط الموقع الحقيقي (https).
- البيانات محفوظة في `data/db.json` — خذ منه نسخة احتياطية دورياً.
